# Student Task Manager

## 1. Project Description

Student Task Manager is a simple web application designed to help students organize and manage their daily tasks in one place.

## 2. Team Members

* **Student 1:** Mehreen Naz
* **Student 2:** Wardah Zubair

## 3. Features

* Add tasks with a title and description.
* Display tasks in a list.
* Mark tasks as completed.
* Delete tasks.
* Search for tasks.
* Responsive layout for different screen sizes.

*Note: Features will be completed and tested as development progresses.*

## 5. Git Workflow

We use Git to track project changes and GitHub to store and collaborate on the project. We create branches for features, commit changes, push branches to GitHub, and use Pull Requests for code review and merging.

## 6. Branches

* `main` — Main project branch.
* `feature/task-form` — Task input form.
* `feature/task-style` — Styling and layout improvements.
